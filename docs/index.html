A command palette for tmux

Press Ctrl Space, type a few letters, hit enter. Jump to any pane by name, preview it live, run any tmux command, switch themes — or build your own palettes from a shell command.

Install Star on GitHub
$curl -fsSL https://raw.githubusercontent.com/vothanhdat/tmux-palette-rs/master/install.sh | sh

Real recording, no edits: Ctrl Space → type vite → jump · Find Pane with live previews · Switch Theme

Features

Everything in tmux, a few keystrokes away

Panes, windows, sessions, every tmux command and your own scripts — one fuzzy search box, ranked as you type.

Find Pane

See a pane before you switch to it

The session → window → pane tree on the left, the highlighted pane's live screen on the right — in its own colors, updating while you look. Two bash panes are no longer a guessing game.

  • Filter by title, session, window, running command, path — or the AI agent running in it (claude, codex, aider…)
  • Or skip it entirely: panes surface inline in the main palette as you type
  • Resize with Alt = / Alt -; the size sticks
Command prompt

A prefix + : that tells you things

A drop-in replacement for tmux's command prompt. Every command from tmux list-commands, searchable by name and alias, grouped by topic and captioned with what it actually does.

  • Tab completes and cycles through matches, Shift Tab goes back
  • Type a full command name and its flags expand below — optional or required, each described
  • Enter runs it, exactly like the built-in prompt
Themes

13 themes, previewed live

Arrow through the list and the palette repaints as you go. Enter saves, Esc puts it back.

  • Shades of Purple, Dracula, Tokyo Night, Catppuccin, Gruvbox, Nord, Rosé Pine, Kanagawa, Solarized…
  • A transparent Terminal theme that follows your terminal's own colors
  • Drop a JSON file in themes/ and it shows up in the switcher
Custom palettes

Turn any command into a palette

One JSON file per palette. Point it at a shell command — each output line becomes an item, {} is the one you picked — and bind a key to its name.

  • Git branches, GitHub PRs, Docker logs, npm scripts, project switchers — examples included
  • Or print a JSON array for per-item icons, colors and descriptions
  • Actions run tmux commands, shell commands, popups (lazygit, btop…) or other palettes

One static binary

No runtime, no Bun, no Node. The binary is the launcher and the palette. Opens fast enough to live on a key.

Fuzzy, with aliases

Multi-word search, plus initials for free: nw is New Window, sh is Split Horizontal.

Keyboard and mouse

Ctrl P/N, arrows, PageUp/Down — or click rows and scroll the wheel.

Mobile-aware

Goes fullscreen on narrow terminals, so it works over SSH from Blink or Moshi on a phone.

Config that survives updates

Everything lives in ~/.config/tmux-palette/*.json. Add commands, hide built-ins, resize — no fork.

Interactive commands work

Actions run after the popup closes, so confirm-before and command-prompt get your keyboard.

Install

Up and running in a minute

Prebuilt for Linux x86_64, Linux arm64 and macOS on Apple Silicon (Linux builds are static musl). Other platforms build from source. tmux 3.4+ recommended.

Downloads the right prebuilt to ~/.local/bin/tmux-palette — no toolchain needed.

curl -fsSL https://raw.githubusercontent.com/vothanhdat/tmux-palette-rs/master/install.sh | sh

Bind it in ~/.tmux.conf (the installer prints this line for you), then tmux source-file ~/.tmux.conf:

bind -n C-Space run-shell "~/.local/bin/tmux-palette"

Add to ~/.tmux.conf, then press prefix I. The default branch ships prebuilts, so nothing compiles.

set -g @plugin 'vothanhdat/tmux-palette-rs'
# all optional:
set -g @palette-key 'C-Space'              # main palette, no prefix needed
set -g @palette-find-pane-key 'M-f'        # straight to Find Pane
set -g @palette-command-prompt-key ':'     # replace prefix + :
set -g @palette-width '60%'                # percent of the client, or columns

Needs a stable Rust toolchain (rustup.rs).

git clone https://github.com/vothanhdat/tmux-palette-rs ~/Sites/tmux-palette
cd ~/Sites/tmux-palette
cargo build --release

Then bind the binary:

bind -n C-Space run-shell "~/Sites/tmux-palette/target/release/tmux-palette"
Customize

A palette is a JSON file

Save this as ~/.config/tmux-palette/palettes/git-branches.json and bind a key to its name. That's the whole plugin.

{
  "title": "Git Branches",
  "command": "git branch --format='%(refname:short)'",
  "action": {
    "tmux": "send-keys 'git checkout {}' Enter"
  }
}
bind -n M-b run-shell "~/.local/bin/tmux-palette git-branches"

Also in ~/.config/tmux-palette/: commands.json to add items, hidden.json to hide built-ins, theme.json, sizing.json, aliases.json. See the README.

Keys

Muscle memory

Ctrl SpaceOpen the palette
type…Filter commands, and panes across every session
↑ ↓ · Ctrl P/NMove the selection
PgUp PgDnJump 10 rows
EnterRun it
EscClose, or back out of a nested palette
Tab · Shift TabComplete and cycle (command prompt)
Alt = · Alt -Grow / shrink Find Pane
